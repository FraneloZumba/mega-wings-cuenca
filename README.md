# Mega Wings Cuenca — Demo web simplificada

Versión ligera para prospección:

- `public/logo.png`
- `public/wings-generic.jpg`

Todas las secciones visuales reutilizan la misma foto genérica de alitas para ahorrar tiempo.
Si el cliente se interesa de verdad, luego se reemplazan por fotos reales y se afina el contenido.

## Ejecutar

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

## Notas

- Reemplaza `WHATSAPP_NUMBER` en `app/page.tsx` con el número oficial.
- `logo.png` viene de la referencia proporcionada.
- `wings-generic.jpg` es la imagen comodín para toda la demo.
